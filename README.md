Girls-Frontline Pixel Dungeon（New）
=======================
项目全称：少女前线像素地牢 [Girls-Frontline Pixel Dungeon]
软件缩写：少前地牢 [GFPD]

本项目是基于散爆网络（SUNBORN）开发的策略战术养成类游戏《少女前线》剧情元素的同人游戏。

本项目是开发者https://github.com/00-Evan<br/>制作的游戏《https://github.com/00-Evan/shattered-pixel-dungeon》<br/>（破碎像素地牢）的1.2.3版本的分支项目；部分代码与素材取自开发者https://github.com/PATRIOT-BALL<br/>的同名项目《Girls-Frontline Pixel Dungeon》；本项目基于以上两者进行开发，也可以视作后者的迭代。

目前，《少前地牢》提供安卓平台与Windows PC平台版本，已上线GitHub平台，并遵循GPL-3.0守则进行开源，本项目完全免费且公开。
